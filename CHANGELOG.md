# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2026-06-01

### Added
- ✨ **Search Functionality** - Search students by ID or Name
- ✨ **Update Functionality** - Modify existing student records
- ✨ **Delete Functionality** - Remove student records
- ✨ **Email Field** - Added optional email field for students
- ✨ **Timestamps** - Track when students are added to the system
- ✨ **Input Validation** - Comprehensive validation for all inputs
- ✨ **Better UI** - Formatted table output with headers
- ✨ **Student Counter** - Display total number of students
- ✨ **Database Initialization** - Auto-create CSV file with headers

### Improved
- 🔧 **Error Handling** - Better exception handling with user-friendly messages
- 🔧 **Code Structure** - Refactored into modular functions
- 🔧 **Validation** - Age range validation (5-100 years)
- 🔧 **Duplicate Check** - Prevent duplicate student IDs
- 🔧 **Menu Display** - Better formatted and organized menu
- 🔧 **Documentation** - Added comprehensive README and inline comments

### Fixed
- 🐛 Fixed file handling issues
- 🐛 Improved error messages
- 🐛 Better empty input handling

## [1.0.0] - 2026-06-01

### Initial Release
- Basic student management functionality
- Add students to CSV file
